# Custom Installer

Custom Installer — аккуратный установщик APK, XAPK и APKS в нижней панели. Ставит приложения через root, не трогая системный установщик.

Релиз тестировался на **vivo V2352GA, Android 16 (SDK 36)**, но установщик **работает на любых прошивках и устройствах** с Android 12+ и root-доступом (Magisk, KernelSU, APatch, обычный `su`).

## 🚀 Установка приложений

Custom Installer ставит APK, XAPK и APKS через root, используя сессионный `pm install-create` / `install-write` / `install-commit` с `install-abandon` при ошибке, не открывает системный установщик, не редактирует `/system`, не запрашивает `INSTALL_PACKAGES` и не использует `pm disable`. Для split-пакетов выбирается минимальный набор из base, языка, ABI и плотности, а если сплит не подходит, установщик переходит на universal; XAPK — это Android App Bundle в формате ZIP с манифестом, набором APK и OBB, а APKS поддерживает `universal.apk` и Play Asset Delivery. Отдельная кнопка временно убирает стоковый `com.android.packageinstaller` для пользователя 0, а для пакетов с `targetSdk` ниже 23 и тестовых сборок добавляются `--bypass-low-target-sdk-block` и `-t`.

## 🎨 Интерфейс

Интерфейс построен на Material Design 3 с динамической темой Monet и аккуратной нижней панелью установки. Можно выбрать системный Monet или фиксированные акценты вроде фиолетового, синего, зелёного, красного и монохрома, включить тёмную тему или чистый чёрный для OLED, а также настроить скругление шторки в диапазоне 8–28 dp и затемнение фона от 0 до 60%. После установки APK можно удалять автоматически, если у файла есть прямой путь и доступен root, а если у приложения нет лаунчера, кнопка «Открыть» заменяется на «О приложении».

## 🔍 Детали приложения

Перед установкой показываются иконка, название, пакет, тип установки (новое, обновление, даунгрейд или несовпадение подписи), версия, размер, минимальный и целевой SDK, поддерживаемые ABI и состав бандла для XAPK и APKS. Отдельно выводится статус подписи и список разрешений: опасные выделяются, а новые относительно установленной версии получают бейдж «Новое». Для выбранного файла считается SHA-256, тап по строке копирует хэш и открывает проверку на VirusTotal.

## 🛠 Сборка

Для сборки нужны Android SDK Platform 36, Build-tools 36.0.0 и JDK 17 или новее. Запусти `bash tools/build.sh` — скрипт соберёт `dist/CustomInstaller.apk` примерно на 120 КБ через aapt2, javac и d8, без Gradle и Compose. Подпись выполняется ключом из `keystore/custominstaller.jks`.
